Expand description

Polls all tracked processes via non-blocking try_wait() every poll_interval. When a process has exited, it handles automatic restart with backoff and rate limiting, or removes it from the DashMap and emits a ProcessExitEvent.

The reaper does not block. Backoff waits are handled by checking next_eligible_restart on each poll cycle.
