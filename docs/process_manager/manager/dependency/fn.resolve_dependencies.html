pub(crate) fn resolve_dependencies(

    depends_on: &[DependencyRef],

Expand description

Resolve DependencyRef::Label to a concrete ProcessId by finding the first process with that label in Running or Starting state.

Starting is accepted because the process is alive and will soon transition to Running. The caller (all_deps_running) will call state() to perform the Starting → Running transition and verify.

Returns Ok(resolved_ids) if all dependencies resolve, or Err(DependencyNotFound) if a label dependency cannot be resolved.
