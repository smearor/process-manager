Expand description

A managed child process.

Represents a running or completed child process tracked by ProcessManager. The child handle is always Some — even forked processes (with setsid()) are tracked with their Child handle for stop/reaper operations.

Fields§

§id: ProcessId

Unique identifier assigned by the ProcessManager.

§pid: u32

The PID of the child process.

§program_name: String

The program name (for error reporting).

§label: String

The label under which this process was started (for grouped operations).

§terminate_on_exit: bool

Whether to terminate this process when the ProcessManager is dropped.

§config: Arc<ProcessConfig>

The configuration this process was started with.

§child: Option<Child>

The child process handle. Always Some — forked processes are also tracked (with setsid() applied via pre_exec).

§stdout_reader: Option<JoinHandle<()>>

Join handle for the stdout reader thread, if stdout was piped.

§stderr_reader: Option<JoinHandle<()>>

Join handle for the stderr reader thread, if stderr was piped.

pub fn is_running(&mut self) -> bool

Whether the child process is still running.

Uses non-blocking try_wait() on the Child handle for all processes (forked and non-forked). No /proc polling needed since the Child handle is always available.

Source

pub fn try_wait_exit(&mut self) -> Option<ExitStatus>

Non-blocking check whether the child has exited.

Returns Some(ExitStatus) if the process has exited, None if it is still running or the status could not be determined.

Source

pub fn wait(&mut self) -> Result<ExitStatus>

Wait for the child process to exit. Returns the exit status.

Blocks until the child process exits. Only available for non-forked processes (forked processes should use is_running() with the reaper).

Source

pub fn send_signal(&mut self, signal: KillSignal) -> Result<()>

Send the configured kill signal to the child process.

Uses nix::sys::signal::kill(Pid::from_raw(pid), signal) for both forked and tracked processes, since std::process::Child::kill() always sends SIGKILL and does not respect kill_signal.

Source

pub fn force_kill(&mut self) -> Result<()>

Force-kill the child process with SIGKILL.

This is the escalation step after SIGTERM + grace period. Uses nix::sys::signal::kill(Pid::from_raw(pid), Signal::SIGKILL).

Source

pub fn join_readers(&mut self, timeout: Duration)

Join reader threads with a timeout.

After the child process exits, its stdout/stderr pipes are closed and the reader threads should terminate. This joins them with a short timeout to avoid lingering threads. Threads that don’t finish within the timeout are detached (logged as warning).
