1//! Process management for Wayland compositors and desktop launchers.
2//!
3//! `smearor-wrot-process` provides a [`ProcessManager`] that spawns, tracks,
4//! and terminates child processes with support for:
5//!
6//! - **Labels** — group processes and operate on them collectively ([`stop_label`], [`restart_label`])
7//! - **Forked mode** — detach processes via `setsid()` while keeping them tracked
8//! - **Reaper thread** — detect process exits without a thread-per-process blocking `wait()`
9//! - **Graceful shutdown** — `SIGTERM` → `SIGKILL` escalation with configurable timeout
10//! - **Wayland sockets** — automatically set `WAYLAND_DISPLAY` when a [`Socket`] is configured
11//! - **Terminate-on-exit** — kill processes when the manager is dropped
12//!
13//! # Key types
14//!
15//! - [`ProcessManager`] — central handle for spawning, stopping, and inspecting processes
16//! - [`ProcessConfig`] — builder-based configuration for each spawned process
17//! - [`ProcessId`] — opaque identifier assigned by the manager
18//! - [`ProcessInfo`] — lightweight snapshot of a running process (no `Child` handle)
19//! - [`ProcessExitEvent`] — emitted by the reaper when a process exits
20//! - [`KillSignal`] — `SIGTERM` or `SIGKILL` (used for termination config)
21//! - [`Signal`] — broader signal enum for general process control (`SIGHUP`, `SIGUSR1`, `SIGSTOP`, etc.)
22//! - [`StdioConfig`] — `Inherit`, `Null`, or `Piped` for stdin/stdout/stderr
23//!
24//! # Usage
25//!
26//! ```no_run
27//! use process_manager::{ProcessConfig, ProcessManager, StdioConfig};
28//!
29//! let manager = ProcessManager::new();
30//!
31//! let config = ProcessConfig::builder()
32//!     .command("sleep".to_string())
33//!     .args(vec!["10".to_string()])
34//!     .stdout(StdioConfig::Null)
35//!     .stderr(StdioConfig::Null)
36//!     .build();
37//!
38//! let id = manager.start("worker", &config).unwrap();
39//! assert_eq!(manager.is_running(id), Some(true));
40//!
41//! manager.stop(id).unwrap();
42//! assert!(manager.is_empty());
43//! ```
44//!
45//! [`stop_label`]: ProcessManager::stop_label
46//! [`restart_label`]: ProcessManager::restart_label
47//! [`Socket`]: process_manager_socket::Socket
